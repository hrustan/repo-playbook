# Research notes

Numbered, dated, point-in-time. Start from [0000-template.md](0000-template.md);
every note gets a row in the repo README's doc index in the same commit.

## What lives here vs in adr/

- **research/** answers a *question*: findings, numbers, sources. Snapshots — never
  rewritten, banner-and-supersede instead.
- **adr/** records a *decision*: what we chose and rejected. Immutable.

A research note that ends in a decision links to the ADR it produced; the ADR cites
the note as evidence.
